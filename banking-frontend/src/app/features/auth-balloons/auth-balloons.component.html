🔒 Politique de confidentialité — T€chno-Bank

1. Responsable du traitement

T€chno-Bank, établissement bancaire fictif développé dans le cadre d'un projet académique (TFE — EAFC Uccle, 2025-2026). Contact : technobank@eafc.be

2. Données collectées

Dans le cadre de votre inscription et de l'utilisation de nos services, nous collectons les données suivantes :

  • Nom, prénom, adresse email
  • Données bancaires : numéros de compte, soldes, opérations
  • Données de carte bancaire : numéro masqué, date d'expiration
  • Historique des virements et placements
  • Messages échangés via le chatbot de support

3. Finalités du traitement

Vos données sont utilisées pour :

  • La gestion de votre compte bancaire
  • L'exécution des virements et opérations financières
  • La sécurisation de votre accès (authentification JWT)
  • Le support client via le chatbot Alex
  • La génération de relevés de compte

4. Base légale

Le traitement est fondé sur votre consentement explicite (Art. 6.1.a RGPD) ainsi que sur l'exécution du contrat bancaire (Art. 6.1.b RGPD).

5. Durée de conservation

Vos données sont conservées pendant toute la durée de votre relation bancaire, puis archivées conformément aux obligations légales (10 ans pour les données comptables).

6. Sécurité des données

T€chno-Bank met en œuvre les mesures suivantes pour protéger vos données :

  • Chiffrement des mots de passe (BCrypt)
  • Authentification par token JWT avec expiration
  • Protection CORS limitée au domaine autorisé
  • Accès restreint par rôles (CLIENT / ADMIN)

7. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès — consulter vos données personnelles
  • Droit de rectification — corriger vos informations
  • Droit à l'effacement — demander la suppression de votre compte
  • Droit à la portabilité — recevoir vos données dans un format structuré
  • Droit d'opposition — vous opposer à certains traitements

Pour exercer ces droits, contactez-nous via le chatbot ou à l'adresse technobank@eafc.be

8. Cookies

T€chno-Bank utilise uniquement le stockage local (localStorage) pour maintenir votre session de connexion. Aucun cookie de tracking ou publicitaire n'est utilisé.
